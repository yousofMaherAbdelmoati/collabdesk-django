# DJ-006 — Reliable Django Redis cache

## Result

PASS — the cache functionality in this task was implemented and the targeted
SQLite unit checks plus Redis/PostgreSQL Compose integration checks passed.

## Changes

- Added cache-aside ticket statistics at `GET /api/tickets/stats`. Results are
  scoped to the authenticated user's existing visibility rules; agents also
  receive their own assignment statistics.
- Added admin-only `GET /api/tickets/cache-metrics` for best-effort hit/miss
  counters.
- Added configurable `CACHE_NAMESPACE`, `CACHE_VERSION`,
  `TICKET_STATS_CACHE_TTL_SECONDS`, `TICKET_STATS_CACHE_LOCK_TTL_SECONDS`, and
  `TICKET_STATS_CACHE_LOCK_WAIT_SECONDS` settings. Django Redis uses the
  namespace and version as its key prefix/version.
- Added a generation key to invalidate all derived ticket/agent statistics
  after committed ticket or message create/update/delete changes. The claim
  and resolve service operations explicitly invalidate because their
  `QuerySet.update()` calls bypass model signals.
- Added a bounded cache-miss lock. It uses a random ownership token and Redis
  Lua compare-and-delete release; lock contention waits briefly for a fill,
  then computes from PostgreSQL. Failed cache operations also compute from
  PostgreSQL.
- Added cache correctness, invalidation, per-user separation, agent isolation,
  metrics, outage fallback, and concurrent-miss tests. The Redis integration
  test has a unique key prefix and does not flush Redis.

## Security notes

- PostgreSQL remains the sole correctness and authorization boundary. Cached
  values and locks never grant access, enforce permissions, or decide ticket
  workflow state.
- Cache keys include numeric user id and role but no ticket text, message body,
  email address, access token, or other customer content. Agent entries are
  per-agent rather than cross-agent aggregate data.
- Cache, lock, metric, and invalidation errors are swallowed only after a safe
  PostgreSQL fallback is selected. Cache failure cannot roll back a durable
  ticket/message write.
